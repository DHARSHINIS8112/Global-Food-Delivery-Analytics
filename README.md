 Global Food Delivery Analytics Dashboard

Project Overview
    The **Global Food Delivery Analytics** project is an interactive Power BI dashboard designed to analyze food delivery business performance. It provides insights into revenue, orders, customer experience, delivery operations, and restaurant performance using an 8,000-row food delivery dataset.

 Objectives
- Analyze total orders, revenue, discounts, and restaurant profitability.
- Evaluate delivery time, distance, and customer ratings.
- Understand customer ordering patterns across different channels.
- Compare business performance across cities, cuisines, and restaurant price tiers.
- Build interactive dashboards to support data-driven decision-making.

 Tools & Technologies
- **Power BI Desktop** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and KPI calculations
- **Data Modeling** – Relationships between fact and dimension tables

 Dataset Details
The project uses an 8,000-row food delivery dataset containing information about:

- Order details and order value
- City and cuisine categories
- Restaurant price tiers
- Order channels
- Discounts and restaurant net margins
- Delivery time and distance
- Customer ratings
- Weather conditions and peak-hour information

 Data Preparation
The following data preparation activities were performed:

- Loaded and explored the dataset in Power BI.
- Cleaned and transformed data using Power Query.
- Created calculated categories such as Delivery Type, Fulfillment Status, Profitability Status, Discount Category, and Distance Category.
- Created dimension tables for City, Cuisine, Channel, Weather, and Restaurant Price Tier.
- Established relationships between fact and dimension tables.
